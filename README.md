# Loja de Instrumentos Musicais

Este projeto consiste no desenvolvimento de um site para uma loja de instrumentos musicais.
A página apresentará diferentes instrumentos e acessórios, organizados de forma simples e intuitiva.
O objetivo é criar uma experiência que permita aos usuários conhecer e encontrar produtos da loja.
Ao longo do projeto, novas funcionalidades e melhorias serão adicionadas à aplicação.
